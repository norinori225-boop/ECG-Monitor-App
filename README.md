# 救急車ベッドサイドモニター シミュレーター

救急隊・救急救命士の **想定訓練** 用に、救急車内のベッドサイドモニター表示を再現する Web アプリです。
指導者が操作画面で数値を入力して「反映」を押すと、モニター画面（PC・大型モニター・TV）の表示がリアルタイムに変わります。

> [!WARNING]
> **本ソフトウェアは訓練・教育用のシミュレーターです。医療機器ではありません。**
> 実際の患者の監視・診断・治療判断には絶対に使用しないでください。
> 表示される波形・数値は模擬的に生成したもので、医学的な正確性は保証しません。

---

## 特長

- **ファイル 1 つで動作**：`index.html` をブラウザで開くだけで使えます。インストールは不要です。
- **オフライン対応**：外部ライブラリやフォントを読み込まないので、ダウンロードしておけばインターネットなしで動きます。
- **別端末からの操作（クラウド同期）**：Supabase を設定すると、スマホで操作してタブレットに表示するなど、別々の端末・別々の回線でも同期できます。
- **実機に近い表示**：25 mm/s 相当の掃引表示、心拍同期音、アラーム、NIBP 測定演出などを再現しています。

## 画面構成

| 位置 | 表示内容 |
|---|---|
| 左側（上から） | HR、NIBP（収縮期／拡張期・平均血圧・測定時刻）、SpO2、RR |
| 左下 | EtCO2（**使用時のみ**、RR の左側に表示） |
| 中央〜右側 | 心電図（II 誘導）、SpO2 脈波、CO2 波形（**EtCO2 使用時のみ**） |

## 対応している心電図

| 分類 | 内容 |
|---|---|
| 洞調律 | 洞調律、洞性頻脈、洞性徐脈 |
| QRS 幅 | ワイド QRS（洞調律・洞性頻脈・洞性徐脈・各種房室ブロック・AF・AFL に設定可） |
| ST 変化 | ST 上昇／ST 低下（mm 指定。J 点が基線からずれる波形で表示） |
| ブロック | 洞房ブロック、1 度房室ブロック、2 度房室ブロック（ウェンケバッハ型／モビッツ II 型）、2:1 房室ブロック、3 度（完全）房室ブロック、右脚ブロック、左脚ブロック |
| 頻脈性不整脈 | 心房細動（AF）、心房粗動（AFL）、発作性上室頻拍（PSVT）、心室頻拍（脈あり） |
| 心停止 | 心室細動（粗い／細かい）、無脈性 VT、PEA、心静止 |
| ペーシング | 心室ペーシング（VVI）、房室順次ペーシング（DDD）、ペーシング不全（捕捉不全） |
| 期外収縮 | PVC（散発・二段脈・三段脈・2 連発・ショートラン・多源性）、PAC |

心停止リズムを選ぶと、SpO2 脈波・SpO2 値・血圧は自動で「---」になります（手動で切り替えることもできます）。

## 演出機能

- **心拍同期音**：QRS に合わせて鳴ります。SpO2 が下がると音程が低くなります。
- **アラーム**：上下限の逸脱で数値が点滅し、メッセージ表示と音が出ます。VF・VT・心静止・無呼吸は高優先度（赤）です。上下限値は操作画面で変更できます。
- **消音**：消音ボタンで 2 分間消音し、もう一度押すと解除します。残り時間はモニター・操作画面の両方に表示されます。消音中に同期音も止めるかどうかを選べます。
- **数値の自然な変化**：反映した値まで 5〜60 秒かけてなめらかに変わります。小さな揺らぎも付けられます（OFF にもできます）。
- **NIBP 測定演出**：加圧から減圧、結果表示まで約 20 秒かけて再現します。自動測定（2.5／5／10／15 分ごと）にも対応しています。
- **プリセット**：正常、ショック、STEMI、低酸素、完全 AVB、VF、心静止、ROSC。

## 使い方

### 画面の切り替え

| URL | 画面 |
|---|---|
| `index.html` | デモ（モニター＋操作パネルを 1 画面に表示） |
| `index.html?mode=monitor` | モニター表示専用 |
| `index.html?mode=control` | 操作パネル専用 |

### 1 台の PC で、TV・大型モニターに表示する

1. PC と TV・大型モニターを HDMI でつなぎ、Windows なら `Win + P` →「拡張」を選びます。
2. `index.html?mode=monitor` を開き、ウィンドウを TV 側へ移します。画面をクリックすると全画面表示になり、音が出るようになります。
3. 同じブラウザで `index.html?mode=control` を別ウィンドウで開き、手元の画面で操作します。
4. 数値を入力して **「反映」** を押すと、モニターに表示されます。

モニター画面と操作画面は、**同じ PC の同じブラウザ内** で同期します（`BroadcastChannel` と `localStorage` を使用）。

### スマホで操作し、タブレットに表示する（クラウド同期）

最初に [SUPABASE_SETUP.md](SUPABASE_SETUP.md) の手順で、`index.html` に Supabase の URL とキーを設定しておきます。

1. タブレットでモニター画面（`?mode=monitor`）を開きます。画面に 4 桁のルーム番号が表示されます。
2. スマホで操作画面（`?mode=control`）を開き、「クラウド同期」欄にルーム番号を入力して「接続」を押します。
3. 数値を入力して **「反映」** を押すと、タブレットに表示されます。

スマホとタブレットは、別々の回線（4G/5G と Wi-Fi など）でもつながります。クラウド同期を使うときは、両方の端末にインターネット接続が必要です。

### オンラインで試す

GitHub Pages で公開している場合は、ブラウザで開くだけでデモ画面を試せます。

### TV で表示するときの注意

- 画面の端が切れる場合は、TV の画面サイズ設定を「ジャスト」や「フルピクセル」にします。
- PC の省電力設定で、スリープとディスプレイの電源オフを「なし」にします。
- HDMI でつなぐと、音は TV から出ることが多いです。PC のスピーカーから出したいときは、OS の音の出力先を切り替えてください。

## 仕組み

- 操作画面の「反映」で、状態（リズム・数値・設定）を JSON で送信します。
  - 同じブラウザ内では `BroadcastChannel` と `localStorage` で同期します。
  - クラウド同期では Supabase Realtime の Broadcast を使い、ルーム番号ごとのチャンネルで中継します。データベースには何も保存しません。
- 心電図は、P 波・QRS・T 波などを数式で合成し、リズムごとのタイミング規則で生成しています。VF・AF・AFL の基線は連続関数で作っています。
- 描画は Canvas の掃引方式（1 画面 6 秒）です。

## 動作環境

Chrome / Edge / Safari / Firefox の最新版

## 既知の制限

- 心電図は II 誘導の 1 誘導のみです。
- ブラウザの仕様上、音を出すにはモニター画面を一度クリック（タップ）する必要があります。
- 特定メーカーの製品とは関係ありません。画面デザインは一般的なベッドサイドモニターを参考にした独自のものです。
